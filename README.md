# MyFacilitator — AI-Powered Workshop Facilitation

Welcome to the MyFacilitator project repository. This application provides AI-powered workshop facilitation that transforms meetings into engaging, productive sessions.

## Project Info

- **Production URL**: [https://friendly-ai-sessions.vercel.app](https://friendly-ai-sessions.vercel.app)
- **Backend**: [https://friendly-ai-sessions-production.up.railway.app](https://friendly-ai-sessions-production.up.railway.app)

## Architecture

This project uses a two-service architecture:

| Layer | Technology | Hosting |
|-------|-----------|---------|
| Frontend | React + Vite + TypeScript + TailwindCSS | Vercel |
| Backend API | Python Flask + PostgreSQL | Railway |

The frontend communicates with the Railway backend via a thin API client (`src/lib/api.ts`). There is **no Supabase dependency** — the backend is a custom Flask API backed by PostgreSQL.

## Deployment

### Frontend (Vercel)

The frontend is deployed automatically on every push to `main` via Vercel. No manual steps required.

### Backend (Railway)

1. Connect your GitHub repository to Railway
2. Railway will automatically detect the `Dockerfile` in the `supabase_proxy` directory for the backend
3. Configure the following environment variables in Railway:
   - `DATABASE_URL`: Your PostgreSQL connection string
   - `OPENAI_API_KEY`: Your OpenAI API key
   - `JWT_SECRET`: Secret for JWT token generation
   - `STRIPE_SECRET_KEY_LIVE` / `STRIPE_SECRET_KEY_TEST`: Stripe keys
   - `STRIPE_WEBHOOK_SECRET_LIVE` / `STRIPE_WEBHOOK_SECRET_TEST`: Stripe webhook secrets
   - `ALLOWED_ORIGINS`: Comma-separated list of allowed frontend origins

## Local Development

```sh
# Step 1: Clone the repository
git clone https://github.com/Tipingouin17/friendly-ai-sessions.git

# Step 2: Navigate to the project directory
cd friendly-ai-sessions

# Step 3: Install the necessary dependencies
npm install

# Step 4: Copy the environment template and fill in your values
cp .env.example .env

# Step 5: Start the development server
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your values. See `.env.example` for full documentation.

Key frontend variables:
- `VITE_API_URL` — Railway backend URL (e.g. `https://friendly-ai-sessions-production.up.railway.app`)
- `VITE_API_ANON_KEY` — JWT anon key (generated by the Railway backend)
- `VITE_STRIPE_PUBLISHABLE_KEY` — Stripe publishable key

## Technologies Used
